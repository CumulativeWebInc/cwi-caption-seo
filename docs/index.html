🏷️ Caption SEO Analyzer v1.0.0

Deterministic, runs 100% in your browser — no network calls, no data leaves this page. Paste a draft caption, your on-screen text, and the spoken-audio transcript; it checks keyword coverage of the track title / artist name across all three slots, flags missing keyword slots, and validates hashtag counts against 2026-research-based ranges per platform. Deep-link any analysis with ?share= URLs.

Honest limits

  • This tool counts words and hashtags. It does not know TikTok's, Instagram's, or Threads' real ranking algorithms — nobody outside those companies does.
  • Hashtag ranges (IG 3–5, Threads 1, TikTok 1–2) are 2026-research-based guidance, not platform-verified truth. See RESEARCH.md for sources.
  • Coverage uses whole-word, case-insensitive matching. Stemming, synonyms, and slang are not handled — "vibe" ≠ "vibes".
  • If you give it nothing to analyze, it says so — it will not invent a score.
